## 3. GPU：trial 695 之后的状态

### 3.1 `[DSH]` trial 695 已执行并出结果

Codex 在收到刷机授权前就限额了，**刷机由 DSH 执行**。
完整结果见 `docs/headset-wip/findings/TRIAL-695-RESULT.md`。核心：

```
mali: jobirq probe trial 695 before AUTO spin 0:      raw 0/0 stat 0 mask 0xffffffff raw_same 1
mali: jobirq probe trial 695 sample spin 1000:        raw 0/0 stat 0 mask 0xffffffff raw_same 1
mali: jobirq probe trial 695 sample spin 500000:      raw 0/0 stat 0 mask 0xffffffff raw_same 1
mali: jobirq probe trial 695 loop end spin 1000000:   raw 0/0 stat 0 mask 0xffffffff raw_same 1
mali: version word 0xff5aa5f0 (untouched; no firmware version published) trial 695
mali: MCU status 1 (raw state 1; boot unproven), job irq 0, gpu irq 0
mali: the start loop ended after 1000000 spins (halt seen 0, fatal seen 0)
```

`[DSH]` **这些读数排除了：**
- **mask 假说**：`MASK` 回读 `0xffffffff`（全开），`RAWSTAT` 与 `STAT` bit31 同时为 0，`raw_same=1`
- **`STAT = RAWSTAT & ~MASK`**：若如此 RAW 应保留 bit31，实测 RAW 也是 0
- **时钟**：`cycle 0xae473bbc→0xae4c7b83`、`timestamp 0x225d8280→0x225dbcbf` **都在走**
- **电源**：`gpufreq 0xF3C = 0x3ffc`（12 域全 up，厂商判据 `F3C & 0x3FFC`）
- **AS0 走查**：`mmu irq 0x10000` = bit16 = REQ_COMPLETE（**走查成功**，不是 BUS_ERROR）

### 3.2 剩余唯一现象

> `MCU_STATUS = 1 (ENABLED)`，`RAWSTAT` bit31 从未置位，`version word` 未变，
> 无 HALT、无 FATAL、无 GPU fault。

`[DSH]` **公开世界没有这个状态的先例**（公开的只有 `fatal` 和 `disabled`）。
`mt8196` 的 `fatal` 案例是「取指了但翻译失败」，我们是「连 fault 都没有」。
