## 3. LO / HS 冲突门禁（`p4_capture()`）

**位置：`mtk/mt6895/drivers/audio/hakios.mt6895_headset.c:1067-1093`**

```c
static bool
p4_capture(void)
{
    uint8_t id, vaud, lo, hs, gain;
    if (p4.owned || mode != 4 ||
        !mt6368_read(0x0009, &id) || !mt6368_read(0x1cb2, &vaud) ||
        !mt6368_read(0x2595, &lo) || !mt6368_read(0x2593, &hs) ||
        !mt6368_read(0x23d7, &gain)) {
        return false;
    }
    ...
    if (id != 0x68 || !(vaud & 1) || (lo & 3) || (hs & 3) || (gain & 0x24) ||
        ... ) {
        printf("headset: profile4 capture refused: chip/supply/source/another active path\n");
        return false;
    }
```

### 3.1 门禁清单

| 检查 | 寄存器 | 名称 | 条件 |
|---|---|---|---|
| **LO 冲突** | **`0x2595`** | `MT6368_AUDDEC_ANA_CON13`（`mt6368.h:391`） | **`(lo & 3) == 0`** 才通过 |
| **HS 冲突** | **`0x2593`** | `MT6368_AUDDEC_ANA_CON11`（`mt6368.h:389`） | **`(hs & 3) == 0`** 才通过 |
| 芯片 ID | `0x0009` | — | `== 0x68` |
| VAUD18 | `0x1cb2` | — | **bit0 == 1**（只检查不切换） |
| NLE gain | `0x23d7` | `AFE_DL_NLE_CFG`（`mt6368.h:204`） | `(gain & 0x24) == 0` |

**即：lineout 与 handset 两个输出的低 2 位必须都为 0，profile4 才接管。**

### 3.2 但门禁只检查这 2 位

**`(lo & 3)` 和 `(hs & 3)` 只看 bit0-1。**
**这两个寄存器的其他位、以及其他可能的输出使能位，不在门禁范围内。**

**我没有依据判定 `0x2595`/`0x2593` 的 bit0-1 是否就是全部输出使能。**
**如果扬声器路径由别的寄存器控制，这个门禁不会拦住它。**

## 5. 物理分离录音布置（设计建议）

**目标**：让下一次录音能区分"耳机出声"与"扬声器出声"，并且能判断 gap 是否干净。

### 5.1 核心问题

**当前录音**：第二台手机同时录到耳机与扬声器，无法区分。

### 5.2 建议布置（三种，按区分能力排序）

#### 方案 A：耳机贴麦克风 + 扬声器物理遮挡（**推荐**）

| 项 | 做法 |
|---|---|
| 耳机 | 保持在耳外但**贴近**录音麦克风（约 2–5 cm，正对出音孔） |
| **扬声器** | **用厚布/海绵/胶带物理覆盖手机底部扬声器开孔** |
| 录音手机 | 与耳机同侧，距离固定 |
| 目的 | 即使扬声器也响，被遮挡后衰减明显，可对比 |

**优点**：不需要拆机、不需要软件配合。
**局限**：遮挡衰减量未知，不构成定量隔离。

#### 方案 B：两次对照录音

| 次 | 做法 |
|---|---|
| **B1** | 耳机**拔掉**，只留手机 → 录到的是纯扬声器（若有） |
| **B2** | 耳机**插上**，同位置同音量 → 录到耳机+扬声器 |
| **判据** | **若 B1 有短音而 B2 也有，说明扬声器参与了；若 B1 静音而 B2 有，声源是耳机** |

**优点**：**这是唯一能明确区分的方法**。
**代价**：需要多跑一次不带耳机的试验（或至少一次对照）。

#### 方案 C：耳机电学/声学隔离（最严格）

**用 3.5mm 延长线把耳机引出到另一个房间**，录音手机留在原处。
**若仍录到短音 → 只能是扬声器。**

**局限**：需要延长线；且用户手机是 USB-C，可能需转接。

### 5.3 无论哪种方案都要加的

| 项 | 目的 |
|---|---|
| **录一段静音基线**（不说话、不播放，10 s） | 得到环境底噪，用于判断"杂音"性质 |
| **录一段已知参考**（`reference-711.wav` 走 Android） | 校准录音链增益 |
| **记录录音手机型号与麦克风位置** | 便于复现 |
