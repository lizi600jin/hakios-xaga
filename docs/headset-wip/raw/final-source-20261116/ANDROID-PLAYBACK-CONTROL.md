# Android 播放链对照实验（2026-11-16 20:24）

> DSH。**一次受控的 Android 侧播放，用来区分「Android 没出声」与「录音链没录到」。**

---

## 0. 结论（已按 Codex 复核收窄）

**Android 播放链正常，用户在耳机上听到声音。**

**原文（已撤回）：**
~~「因此 711 录音里 997 Hz 很弱，是录音链的问题，不是 Android 没有出声。
这支持了用户此前的判断：『没录上的可能性更大』。」~~

**🔴 撤回理由**：本次对照与 711 那次录音的**音量档位、手机距离、
录音设备位置与 AGC 状态并未完全匹配**。
**所以只能说「Android 有能力放出人耳可闻的声音」，
不能断言「711 缺参考音必属录音链问题」，也不能据此确认 711 当时录没录到。**

**本次结果排除的是「Android 一贯不发声」这一种解释，不是定位了 711 的成因。**

---

## 1. 为什么要做这个实验

**trial711 的录音里，`reference-711.wav` 的 997 Hz 参考音在频谱上很弱**
（我在 `ACOUSTIC-SOURCE-712` 里测到 1e7–1e8 量级，远低于 100 Hz 与 3000 Hz 成分）。

**有两种可能：**

| # | 可能 | 如何区分 |
|---|---|---|
| A | Android 压根没放出声音 | 播放时抓 AudioFlinger 帧计数 |
| B | Android 放出来了，但录音手机没录到 | 人耳对照 + 帧计数 |

**本实验同时取了这两个证据。**

---

## 2. 实验条件

| 项 | 值 |
|---|---|
| 设备 | 原厂 Android，`slot _a`、`boot_completed=1`、`boot_id` `686cb45c…` |
| **媒体音量** | **`volume_music_headphone = 4`（Max 15，约 27%）** —— 用户要求不要太大，保持原值未提升 |
| **输出路由** | **`Devices: headphone(8)`** |
| 播放内容 | `reference-711.wav`（1536044 B / `b994ddba…`，8 s、48k stereo、**997 Hz 三声各 1 秒**） |
| 播放方式 | `am start -a android.intent.action.VIEW -d file://… -t audio/x-wav` |
| 屏幕 | `isKeyguardShowing=false`（正常唤醒，未绕过凭据） |

**未修改任何音量设置**（我一度准备推到 15，用户要求人耳听、小一点，故保持 4）。

## 5. 这个实验确立了什么

| # | 结论 | 依据 |
|---|---|---|
| **1** | **Android 播放链正常工作** | 帧与写计数推进 + 用户听到 |
| **2** | **4/15 音量经耳机输出人耳可闻** | 用户确认 |
| **3** | **Android 这条路径本身能发出人耳可闻的声音** | 同一播放代码路径、同一文件、同样耳机路由（**但音量档位/距离/AGC 未匹配**） |

---

## 6. 这个实验没有确立什么

| # | 未确立 | 说明 |
|---|---|---|
| 1 | **录音链具体在哪失效** | 不知道是手机距离、麦克风灵敏度、AGC 还是别的 |
| 2 | **711 与 712 录音的手机距离是否一致** | 两轮布置不同，未记录精确距离 |
| 3 | **需要多大音量才能在录音里清晰出现** | 4/15 可闻但对录音手机可能仍太轻；未做音量阶梯实验 |
| 4 | **录音手机的录音质量** | 未校准，无参考电平 |
| 5 | **Android 输出与 codec SGEN 的电平关系** | 两条完全不同的路径，不能互相换算 |

---

## 7. 对结论的影响

**这是「对照实验」，不是对 711/712 试验结果的改判。**

**711 的 `PROFILE_AND_EDGE_TIMING_PASS` 与 `STOCK_RECOVERY` 仍然成立。**
**712 的 `USER_CONFIRMED_HEADPHONE_AUDIBLE` 仍成立。**

**唯一的变化是**：以后若再做录音分析，**不应把「录音里没有 Android 参考音」
直接当作「Android 根本没出声」的证据** —— 本次已证明该路径能出声。

**但不能反过来推断「711 那次没录到一定是录音链问题」** —— 条件未匹配。
