## 3. 🔴 `failures=0` 的判读条件

**按 CMD 与 718 设计，我记录：**

**失败掩码 `failures=0` **只有在同时满足**下面两条**时**才表示「响应被接受」：**

1. **`response_valid == 0x1fff`**（13 词全收到）
2. **`sampled OCS == 0`**

**🔴 若 `OCS != 0`，即使 `failures` 显示 0，那也**是未被计算的 0** ——
因为 `if (out->ocs != 0) goto clean;` 在掩码计算**之前**就跳走了。**

**同理若 `valid != 0x1fff`（部分读失败），`failures=0` 也是未计算值。**

**→ 716/717/718 一致：这个三态判读规则从未改变。**
