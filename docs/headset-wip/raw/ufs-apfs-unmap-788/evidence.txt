What the driver does now, and what it did before
------------------------------------------------
before:  buf_map(bp, &mapped)  ...  buf_biodone(bp)          (mapping leaked)
after:   buf_map(bp, &mapped)  ...  buf_unmap(bp); buf_biodone(bp)

         buf_unmap() on a buffer that was never mapped returns 0 without doing
         anything, and on a non-clustered buffer it also returns 0, so the added
         call is harmless on every path that does not need it.
