# 711 声源结论：SOURCE UNCONFIRMED

## Codex 独立复核（原文摘要）

- HLOG 完整整数校验通过、镜像与参数精确、38 组 on/off/restored、共享位稳定、
  7 条 tone edge verified、初始等待 2.048 s、后续间隔 1.028/1.013/1.013/1.011/1.017 s、
  一次干净关闭、36 字节 ACCDET 恢复、原厂恢复已验证。
- 用户报告在 XNU 期间听到明显三段声音，但不确定来自耳机还是手机扬声器。
  **这是主观听觉证据，SOURCE UNCONFIRMED，不是耳机输出 PASS。**

## 录音结构（Codex 独立解码）

- 原件 `/home/lizi/下载/标准录音+5.mp3`，11143945 B，
  SHA256 `654c41faf6a0aa58e3ded654cbc8ad8088f8855303128b90d8542d37d955da1e`（本轮仍原样保留在该路径）。
- 显著片段约 **71.2–78.35 s** 是**连续且音调变化**的内容，
  **不是三个 1 秒脉冲被 1 秒静音 gap 分开**。
- 观察到的谐波族约 **1.418 kHz（前段）→ 2.262 kHz（中段）→ 3.032 kHz（末段）**。
- **右声道明显强于左声道。**
- 这些是**录音观察**，不是校准过的 codec 频率、声源定位、SPL 或输出失真测量。

## 明确的判据边界

| 不做 | 理由 |
|---|---|
| **不判 mute gap** | 录音结构不是三段脉冲，无法据此评价 `C_MUTE_SW_CTL` 的声学静音效果 |
| **不归因 MP3/AGC** | 无证据，属推测 |
| **不把 bit6 序列等同声学静音** | 寄存器状态 ≠ 声学效果 |
| **不声称 bit6 无效** | 录音结构不符有多种可能 |
| **不声称已排除无关扬声器声源** | 无物理隔离测量 |
| 无精确录音时钟/logbook 对齐 | 尚未建立 |

## DSH 侧独立观察（与 Codex 一致）

我在 ACOUSTIC-SOURCE-712 里用 RMS 包络得到同一段的内部结构是
**约 5.2 秒（71.1–76.3，电平约 1×）+ 约 2.0 秒（76.3–78.3，电平约 2×）连续段**，
与 Codex「连续变调、非三段脉冲」的结论一致。

Goertzel 扫描显示 **997 Hz 在三段都弱（1e7–1e8 量级）**，
即`reference-711.wav` 的 997 Hz 参考音大概率未被录到，
与用户「安卓参考音可能太小」的说法一致。
**但这只是观察，不构成对 Android 播放链的判定。**
