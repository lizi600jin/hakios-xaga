## 0. 一句话

**从 Android 实际运行的 codec 模块里反汇编出耳机上电 45 步、下电 11 步，
寄存器和数值全部提取完毕，可以直接翻译成驱动代码。**

---

## 1. 提取方法

```bash
readelf -sW snd-soc-mt6368.ko | grep FUNC | grep -i hp_
aarch64-linux-gnu-objdump -dr --start-address=0x8be0 --stop-address=0x9358 snd-soc-mt6368.ko
```

`mt_hp_event`（`:0x8be0`，1912 字节）是上电主函数。
它的调用表：

| 调用 | 次数 |
|---|---|
| `regmap_write` | **46** |
| `regmap_update_bits_base` | **20** |
| `usleep_range` | 4 |

**提取到的常量写入 45 条**（其余是条件分支里的重复写）。

### 分三段看

| 段 | 步骤 | 作用 |
|---|---|---|
| **A. 时钟与偏置** | 1-13 | `0x2595/96` 时钟、`0x25a0/01/02` 上电时序、`0x2609/0a` 左右偏置 |
| **B. 参考与 DAC 数字** | 14-25 | `0x2589` 参考、`0x2588` 启动、`0x258a` 数字渐升（`0x0c→0x3c`） |
| **C. 模拟输出使能** | 26-45 | `0x2588` 升到 `0xff`、`0x258a` 经 `0xfc/0xff/0xcf/0xc3/0x03`、最终 `0x2589` 三处置位 |

**关键终值**：
- `0x2588 = 0xff`（DAC 模拟全开）
- `0x258a = 0x03`（DAC 数字就绪）
- `0x2589` bit0/bit1/bit3 置起（输出级使能）

## 4. 这些寄存器在哪

全部在 **`MT6368_AUDDEC_ANA`** 区（`mt6368.h:370` 起）：

```c
#define MT6368_AUDDEC_ANA_CON0   0x2588
#define MT6368_AUDDEC_ANA_CON1   0x2589
#define MT6368_AUDDEC_ANA_CON2   0x258a
...
```

**我们的 `headset=1` 已经 dump 过整个 `AUDDEC_ANA` 区（48 个寄存器），
所以这些地址的读写通路已经验证过能通。**

## 5. 还缺什么（这才是出声的真正门槛）

### 5.1 已验证的

| 项 | 状态 |
|---|---|
| SPMI 读 `AUDDEC_ANA` | ✅ trial 699/700/701 读过 48 项 |
| SPMI 写 `AUDDEC_ANA` | ✅ `configure()` 路径已实现并被 701 的初始化验证 |
| 插入识别 | ✅ trial 701 PASS |

### 5.2 缺的

| # | 缺什么 | 难度 |
|---|---|---|
| 1 | **把 45 步写进驱动** | 小（照抄） |
| 2 | **AFE 路由到 I2S 而非 TDM** | **大** |
| 3 | **MT6368 数字接口（I2S format/clock）配置** | 中 |
| 4 | 音量 / 静音 | 小 |

**第 2 条是真正的门槛**：`hakios.sound.c` 现在走 `PRI_TDM_RX_0` → AW88261（外放），
耳机需要 AFE 输出到 I2S，再进 MT6368 的 DAC。

**`grep mt6368 hakios.sound.c` = 0 命中** —— 声音驱动完全不认识 MT6368。

---

## 6. 建议的两步走

### 第一步：`headset=3` —— 只上电 DAC，不出声（可今晚做）

执行 45 步序列，然后回读验证。

**判据**：
| 寄存器 | 期望 |
|---|---|
| `0x2588` | `0xff` |
| `0x258a` | `0x03` |
| `0x2589` | bit0/1/3 置起 |
| PMIF 错误 | 0 |

**意义**：证明 DAC 真的上电了。这是出声的必要前提。
**风险低** —— 全是 codec 内部寄存器，不碰电源门控。

### 第二步：AFE → I2S 路由（单独一轮）

工作量大，需要改 `hakios.sound.c` 的 AFE 参数、加 MT6368 I2S slave 配置、调时钟。

## 7. 证据边界

| 层级 | 结论 |
|---|---|
| **已证明（反汇编）** | 这 45 步和 11 步是 Android 驱动在耳机事件里写的 |
